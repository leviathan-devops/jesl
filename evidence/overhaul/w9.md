| Detail | Value |
|---|---|
| SYMPTOM | validateDomainModule falsely rejected Http and Llm as "not real tags" |

| FIX | shared.ts isRealTag: `typeof x === "object" || typeof x === "function"` + the Tag identity fields (key/identifier/_id) |
| LESSON | Effect Context.Tag classes are callable constructors — a tag check must accept both shapes |
